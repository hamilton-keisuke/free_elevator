# エレベーターたいけん

Three.js でエレベーターの乗り降りを疑似体験できる、子供向けの簡単なアプリです。

公開ページ: https://hamilton-keisuke.github.io/free_elevator/

## 動かし方

`index.html` をブラウザで開くだけで動きます（Three.js を CDN から読み込むためネット接続が必要）。

ローカルサーバーで動かす場合:

```bash
python3 -m http.server 8765
```

→ http://localhost:8765 を開く

## できること

### エレベーター

- フロア: B1F・1F・2F・3F・4F・5F・R（初期状態: 自分は1Fのそと、エレベーターは4F）
- そと: 階数表示器、▲▼ 呼びボタン（B1F は ▲ のみ、R は ▼ のみ）
- なか: 階数表示器、各階ボタン、開・閉ボタン
- 押せるボタンは画面下のボタン表示エリアにも表示（3D 上のボタンも直接クリック可）
- 「エレベーターにのる」「エレベーターにのらない」「エレベーターからおりる」「エレベーターからおりない」
- 扉が閉まる途中に「開」（そとでは ▲▼）を押すと開け直す
- 扉には窓があり、到着するときは窓の光が下から（上から）だんだん明るくなる。乗っている間は窓の外の景色が流れる

### かいだん

- 「エレベーターのそと」で「◀ かいだんにいく」を押すと、左側の「かいだんエリア」に移動する
  （エレベーターを呼んでいないときのみ）
- かいだんエリアでは「▲ のぼる」「▼ おりる」で1階ずつ上り下りできる（B1F はのぼるのみ、R はおりるのみ）
  - 折り返し階段を、途中の踊り場で向きを変えながら歩く（1階ぶん 8 秒）
  - 踊り場の壁には、そこから行ける階（例: ▲2F ▼1F）を表示
- 「エレベーターのまえにいく ▶」で、その階の「エレベーターのそと」に戻る
- 階段で別の階に移動できるので、「エレベーターが自分のいない階に止まっている」状態を何度でも作れる

## 設定

`index.html` 先頭の `CONFIG` で、フロア構成・初期位置・移動速度などを変更できます。
